# V. GeekPie Sign Server

现代密码学攻击原本可以很优雅。

服务器只返回解密的奇偶性？

RSA bit oracle 能像二分查找一样，一个比特一个比特地把私钥逼出来。

服务器只告诉你 padding 是否合法？

Padding oracle 能逐字节还原明文。

服务器只是比平时慢了半毫秒？

计时攻击能猜出密钥的下一位。

选择明文攻击、Bleichenbacher、故障注入、缓存碰撞、长度扩展——只要目标还愿意交互，哪怕只回一个错误码、一个时钟周期、一个比特，它就会变成预言机，把秘密一片片交出来。

你原本准备了一整套这样的剧本，准备让签名服务器亲口招供。可当你站在机柜前，发现网口灌了环氧树脂，USB 接口焊死，管理 VLAN 在交换机侧被下线。你带来的密文、脚本、探针，全都无处插入。它不接收输入，不返回输出，不泄露错误。

这一切在这台服务器面前都不重要。它根本没有外部接口。
